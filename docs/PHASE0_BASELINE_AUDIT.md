# FASE 0 — AUDIT KOMPREHENSIF & GOLDEN CHARACTERIZATION BASELINE (`BEFORE` REFACTOR)

Dokumen ini merekam **keadaan eksisting (*Before Baseline*)** dari repositori **Nostradamus Quant Terminal (IHSG)** pada Fase 0 sebelum dilakukan perubahan perilaku di Fase 1–5. Seluruh temuan A s/d F telah diverifikasi langsung pada kode sumber dan dikunci melalui *Golden Characterization Test Suite* (`src/utils/phase0CharacterizationSuite.ts`, dapat dijalankan via `npm run test:phase0`).
